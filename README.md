# noirdotdeb.github.io

Personal developer portfolio showcasing production projects, technical architecture, and engineering workflow. Built with a minimalist aesthetic and an automated CI/CD pipeline.

## Tech Stack

* **Frontend:** React, TypeScript, Vite, Tailwind CSS
* **API Integration:** Dynamic public repository fetching via the GitHub REST API
* **Infrastructure & Tooling:** Linux Mint, Git, GitHub Pages, GitHub Actions CI/CD
* **Design System:** Custom dark-mode grid architecture, responsive layouts, and monospace typography

## Architecture & Features

* **Dynamic Source of Truth:** Automatically pulls live repository metadata, descriptions, and language tags directly from GitHub, eliminating hard-coded project maintenance.
* **Automated CI/CD Pipeline:** Every push to the `main` branch triggers a custom GitHub Actions workflow that handles dependency resolution, builds the Vite production bundle, and deploys cleanly to GitHub Pages.
* **Performance Focused:** Engineered with strict TypeScript safety, zero unnecessary bloat, minimal layout shifts, and a clean dark-mode-first visual hierarchy.

## Local Development Setup

To run this project locally for development or testing:

1. Clone the repository:

```bash
 git clone [https://github.com/noirdotdeb/noirdotdeb.github.io.git](https://github.com/noirdotdeb/noirdotdeb.github.io.git)
   cd noirdotdeb.github.io


```

2. Install dependencies:
```bash
npm install

```


3. Start the local development server:
```bash
npm run dev

```
